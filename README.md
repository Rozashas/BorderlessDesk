# BorderlessDesk
내가 쓰려고 만든 전체창모드 강제하는 프로그램

=========================================
실행: App\BorderlessDesk.exe 또는 Borderless Desk.lnk
설치 및 별도 .NET 런타임 설치 없이 실행 가능한 Windows x64 프로그램.

1. 대상 게임/프로그램을 창 모드로 실행합니다.
2. 목록에서 대상 창을 선택합니다. 검색 또는 목록 새로고침을 사용할 수 있습니다.
3. 대상 모니터를 선택하고 전체창 적용을 누릅니다.
4. 자동 유지 체크 시 테두리/크기 변경을 1초 간격으로 감지해 다시 적용합니다.
5. 선택 창 복원 또는 모두 복원으로 원래 테두리와 위치/크기를 복원합니다.
6. X 버튼은 프로그램을 트레이로 숨깁니다. 숨겨진 아이콘 표시에서 찾을 수 있습니다.
7. 트레이 아이콘 더블클릭: 프로그램 열기. 트레이 우클릭 > 복원 후 종료: 모든 창 복원 후 종료.

자동 유지는 적용 시 해당 창에 저장됩니다. 선택한 적용 창의 체크박스를 변경하면 그 창의 유지 설정이 변경됩니다.
실행 시 관리자 권한을 필수 요청합니다. Windows UAC 승인 창에서 사용자가 승인해야 실행됩니다.
독점 전체화면에서 창 모드로 전환하는 기능이나 그래픽 API 후킹은 포함하지 않습니다.
크기 변경을 거부하는 게임, 렌더링 해상도가 고정된 게임, 보호 기능이 있는 게임은 호환되지 않을 수 있습니다.
프로그램 강제 종료/시스템 종료 시 복원은 보장되지 않습니다. 정상 종료는 트레이 메뉴를 사용하세요.

검증: 실제 테스트 창 전체창 크기/테두리 제거, 자동 유지 재적용, 원래 스타일/위치 복원, 다크 UI 렌더 통과.
실제 개별 게임 호환성은 아직 미검증.
